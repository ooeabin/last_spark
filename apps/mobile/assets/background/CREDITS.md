# 배경 에셋 출처

라운지 씬 배경(잿불 바, 기획서 3.1)은 기획서 2.1.1 고정 팔레트 6색으로
`../generate-placeholders.py`(Pillow 필요)가 그린 **자리표시자**다 — Higgsfield로 뽑은
최종 아트로 교체하기 전까지 쓴다(기획서 9.4). 외부 에셋이 아니므로 라이선스 표기 의무가 없다.

## 레이어 구성

맵(월드)은 화면보다 넓고 카메라가 내 캐릭터를 따라 스크롤한다(기획서 2.1.1).
문으로 이어진 4개 구역(잿불 홀·바 카운터·휴게 라운지·추모실, 기획서 3.1)으로
나뉘며, **벽/문 좌표는 `free-roam/model/constants.ts`의 `WALLS`와 생성 스크립트의
레이아웃 상수(FLOOR_Y·HWALL_*·VWALL_*·*DOOR_*)가 서로 일치해야 한다** — 맵 구조를
바꾸면 두 파일을 같이 고칠 것. 월드 레이어 3장은 논리 1440×2160pt
(`WORLD_WIDTH/HEIGHT`)를 2배 해상도로 내보낸 것이고, 비네팅만 카메라와 무관하게
화면에 고정으로 덮이는 스크린 오버레이다.

| 파일 | 좌표계 | 내용 | 픽셀 크기 |
|---|---|---|---|
| `room-base.png` | 월드 | 외벽·인테리어 벽(문 뚫림) + 구역별 톤이 다른 나무 바닥 | 2880×4320, 불투명 |
| `wall-decor.png` | 월드 | 전구줄, 삐뚤어진 액자, 벽 촛대, 술병 선반 | 2880×4320, 투명 배경 |
| `floor-props.png` | 월드 | 광원 글로우 + 구역별 소품(화로 제단, 바 카운터·스툴, 러그·방석·곰인형, 묘비·도깨비불) | 2880×4320, 투명 배경 |
| `vignette.png` | 화면 | 가장자리 비네팅 (캐릭터 위에 덮임) | 1440×2560, 투명 배경 |

최종 아트로 교체할 때 이 레이어 구성·파일명·좌표계를 유지하면 코드(`LoungeScene.tsx`)
수정 없이 파일 교체만으로 끝난다. 월드 크기를 바꾸려면 `constants.ts`의
`WORLD_WIDTH/HEIGHT`와 생성 스크립트의 `LOGICAL_W/H`를 같이 고칠 것.
