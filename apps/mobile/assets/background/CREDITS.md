# 배경 에셋 출처

라운지 씬 배경(잿불 바, 기획서 3.1)은 기획서 2.1.1 고정 팔레트 6색으로
`../generate-placeholders.py`(Pillow 필요)가 그린 **자리표시자**다 — Higgsfield로 뽑은
최종 아트로 교체하기 전까지 쓴다(기획서 9.4). 외부 에셋이 아니므로 라이선스 표기 의무가 없다.

## 레이어 구성 (아래→위 순서로 합성)

| 파일 | 내용 | 규격 |
|---|---|---|
| `room-base.png` | 벽(상단) + 나무 바닥(하단) 베이스 | 720×1280, 불투명 |
| `wall-decor.png` | 삐뚤어진 액자, 벽 촛대, 전구줄 | 720×1280, 투명 배경 |
| `floor-props.png` | 잿불 화로(제단), 러그, 방석, 시든 화분, 낡은 곰인형 | 720×1280, 투명 배경 |
| `vignette.png` | 잿불 글로우 + 가장자리 비네팅 + 떠다니는 불씨 | 720×1280, 투명 배경 |

최종 아트로 교체할 때 이 4레이어 구성과 파일명을 유지하면 코드(`LoungeScene.tsx`) 수정 없이
파일 교체만으로 끝난다. 레이어 수를 바꾸려면 `LoungeScene.tsx`의 이미지 배열을 같이 고칠 것.
