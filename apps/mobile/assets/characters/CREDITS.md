# 캐릭터 에셋 출처

라운지/대기 화면 캐릭터 스프라이트(`cat/idle.png`, `cat/walk.png`)는 기획서 2.1.1
큐트-흑화 카툰 스타일(통통한 SD 고양이 + 머리 위 도깨비불)로
`../generate-placeholders.py`(Pillow 필요)가 그린 **자리표시자**다 — Higgsfield로 뽑은
최종 아트로 교체하기 전까지 쓴다(기획서 9.4). 외부 에셋이 아니므로 라이선스 표기 의무가 없다.

## 규격

- 논리 프레임 60×90(코드의 `CAT_FRAME_W/H`)이고, PNG는 확대 시 깨지지 않게 4배
  해상도로 내보낸다 — 프레임당 240×360px, 가로 8프레임 스트립 → 각 파일 1920×360.
  렌더링 코드는 이미지를 논리 크기×scale로 늘려 그리므로 PNG 해상도는 코드와 무관하다
- `idle.png`: 제자리 들썩임 + 도깨비불 흔들림 + 눈 깜빡임(6번째 프레임)
- `walk.png`: 걷기(발 교차·들썩임 큼) + 도깨비불이 크게 흔들림
- 정면 시점이라 좌우 반전만으로 왼쪽/오른쪽 이동을 표현하고, 위/아래 이동은 같은
  스프라이트로 위치만 바뀐다(뒷모습 프레임 없음)
- 부드러운 카툰 스타일이므로 확대는 Linear 샘플링(픽셀 아트 아님)

char_01~char_12별 개별 스프라이트는 기획서 9.4 에셋 단계에서 교체하기 전까지 전원
이 자리표시자를 공유한다. 교체 시 위 규격(프레임 크기·수, 스트립 구성)을 맞추면
`CharacterSprite.tsx` 수정 없이 파일 교체만으로 끝난다.
